Reference

Built-in objects

The objects the runtime implements, which are the only way any object reaches the world outside the image, and the shapes and message types they use. An image declares one by its trait, instance net : Listener, and the runtime picks how to run it; Packed.Files is declared by its own name. They are declared in the runtime's own header, env, and this page is generated from it.

Console

A console: lines in, and anything out. The runtime runs it on the host's stdin and stdout.

Whatever is written to it is printed on a line of its own. A message whose only field is a string text, such as a Line, prints as that text; any other as its type and fields.

Serves

Path Requests
/ watch -> Line*, write Opaque Watch for every line of input, until it ends; write to print.

Listener

A listener, and the connections it accepts. The runtime runs it as a TCP listener on the address the image configures it with.

Serves

Path Requests
/ control Listen Configured by the image only, with where to listen.
/address read -> Text The bound address, e.g. "127.0.0.1:8080".
/accept watch -> Accepted* Every connection accepted, as it is.
/{conn} watch -> Data*, write Data, remove A connection: watch for the bytes received, until the peer closes; write to send; remove to close our side once everything is sent.

Files

Read-only access to one directory on the host, and nothing above it.

A file's MIME type comes from its extension. Reading a directory answers is_directory, and a listing is sorted by name.

Serves

Path Requests
/ control FilesRoot, read -> Data, stat -> Info, list -> Entry* Configured by the image only, with the directory to serve.
/** read -> Data, stat -> Info, list -> Entry*

Packed.Files

Files packed into the image when it was built, by its includes. It answers as Files does.

Implements FileTree.

Serves

Path Requests
/** read -> Data, stat -> Info, list -> Entry*

Shapes

Traits and protocols the objects above are made of, for headers to use.

Dialer

The other side of a listener run in memory, which an image that imports another can drive it with.

Path Requests
/dial create Data -> Data* Connect, sending the request's bytes, and get back everything the server writes, until it closes the connection.

FileTree

A tree of files, read-only.

Path Requests
/** read -> Data, stat -> Info, list -> Entry*

Terminal

The other side of a console run in memory, which an image that imports another can drive it with: type lines into it, and watch what it prints.

Path Requests
/typed write Line Type a line, as if on stdin.
/printed watch -> Opaque* Everything written to the console, as it is written.

Protocols

Protocol Requests
Connection watch -> Data*, write Data, remove A stream of bytes each way.
Dir list -> Entry*, stat -> Info Something listed.
File read -> Data, stat -> Info Something read whole.

Messages

Text

A string value: a setting, an address, a name.

Field Type
text string

Data

The contents of something, as read answers.

Field Type
mime string Its MIME type, or "" if it isn't known.
data bytes

Info

What stat answers.

Field Type
kind string "file" or "dir".
size i64 In bytes; 0 for a directory.
mime string Its MIME type, or "" if it isn't known.

Entry

One name in a list stream, or what create made.

Field Type
name string
kind string "file" or "dir".

Line

One line of text, without its line ending.

Field Type
text string

Listen

Configures a Tcp listener.

Field Type
address string The address to listen on, e.g. "127.0.0.1:8080".

Accepted

A new connection.

Field Type
conn string Its name under the listener: watch, write or remove /<conn>.
peer string The remote address.

FilesRoot

Configures Files.

Field Type
path string The directory served, relative to the image.
